## Quick Command Examples

Generate 10 videos:
```bash
media-generator 10 -t mp4
```

Generate 10 images:
```bash
media-generator 10 -t jpg
```

Generate 10 audio files:
```bash
media-generator 10 -t wav
```

Need help?
```bash
media-generator --help
```
